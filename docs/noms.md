# Quel nom pour le jeu ?

« 7x42 Green Line Card Game » et « Schotten Totten revisité » sont trop longs et
difficiles à retenir. Critères retenus pour les propositions :

- **court** : un ou deux mots, trois syllabes au plus ;
- **français**, et qui se dit au téléphone sans l'épeler (pour ta grand-mère) ;
- **qui raconte le jeu** : des terrains voisins, des bornes que l'on se dispute ;
- **pas déjà pris** par un jeu connu (vérification rapide en ligne, pas une recherche
  de marque déposée).

## Le trio de tête

```text
╔══════════════════════════════════════════════════════════════════════════╗
║ 1. BORNAGE       Le mot exact : « fixer les limites entre deux terrains  ║
║                  voisins ». Tout le monde l'a entendu chez le notaire ou ║
║                  le géomètre. Trois syllabes, rien à expliquer.          ║
║                                                                          ║
║ 2. SEPT BORNES   Clin d'œil à Mille Bornes, que ta grand-mère connaît    ║
║                  sûrement : impossible à oublier. Seul risque, qu'on     ║
║                  le prenne pour une variante de Mille Bornes.            ║
║                                                                          ║
║ 3. PRÉ CARRÉ     « Défendre son pré carré » : l'expression dit le jeu.   ║
║                  Joli, mais deux mots accentués à l'écrit.               ║
╚══════════════════════════════════════════════════════════════════════════╝
```

Aucun jeu nommé *Bornage*, *Pré carré*, *Lopin* ou *Mitoyen* n'est apparu lors
d'une recherche en ligne (septembre 2026).

## Les autres idées

| Nom | Pourquoi | Bémol |
|---|---|---|
| **Lopin** | « Un lopin de terre » : petit, rural, affectueux | Évoque peu la dispute |
| **Mitoyen** | Le mur que l'on partage avec le voisin | Un peu administratif |
| **Litige** | Ton propre mot : « frontières en litige » | Sonne tribunal |
| **Chicane** | Se chicaner pour trois fois rien ; au bridge, une *chicane* c'est n'avoir aucune carte d'une couleur | Deux sens à expliquer |
| **Clôture** | La barrière entre deux champs | Sonne « fin de partie » |
| **Talus** | Ce qui sépare deux champs à la campagne | Peu parlant |
| **Arpent** | Vieille mesure de terrain, parle aux anciens | Inconnu des plus jeunes |
| **Querelle de clocher** | Rivalité de villages voisins, l'esprit du jeu | Trop long |
| **Tapis vert** | La table de jeu, et un clin d'œil à « Green Line » | Fait penser au casino |

## Le choix

**Un seul nom depuis le 22/10 : Lopin**, pour le jeu comme pour le projet. C'est le
nom qui parle le plus à Sami : un lopin de terre, 7 bornes, 42 cartes. Il est dans la
fiche de règles (`regles/regles.html` : le `<title>`, le grand titre et les pieds de
page), la page du jeu, les rapports, le README et le nom du paquet.

Jusque-là, il y en avait trois :
- **Bornage** pour le jeu (septembre-octobre), le n° 1 du trio ci-dessus ;
- **Lopin n°742** pour le projet et le dossier ;
- **lupin** pour le dépôt GitHub, une faute de frappe.

Sami a renommé le dossier (`lopin`) et le dépôt GitHub (`samiyc/lopin`) le même
jour. Les anciens prompts de `docs/Prompt/` et l'audit du 17/10 gardent les noms de
leur date.
